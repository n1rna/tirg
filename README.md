# n1rna.net

My personal site — blog, projects, and notes. Built with [Astro](https://astro.build/).

## Develop

```bash
npm install
npm run dev      # http://localhost:1234
npm run build    # type-check + build
```

Based on the [astro-erudite](https://github.com/jktrn/astro-erudite) template. MIT licensed.
